## 本项目做了什么

仅限 DSH 适配与必要的独立化改造：

- **DSH 桥接插件**（`bridge/` 与 `shared/`）：新增代码。通过 DSH 已认证连接调用订阅只读接口，把额度与数值会话投影落成本机快照；不复制 Cookie/token，不另开监听端口，不绕过 DSH 授权。
- **宿主模式**：新增"跟随 DSH 窗口"与来源切换；保留原 Codex 来源与手动数据目录。
- **独立化**：改用独立包名、AppId、原生组件名、程序/数据目录、登录任务与快捷方式名，避免与任何已安装挂件冲突；默认不注册 Codex 插件、不使用上游更新源。
- **界面与可靠性修复**：例如气泡收起时同步撤下原生提示框、DSH 离线时不显示伪造额度、隐藏状态不查询额度。
- **验证**：补充了适配相关测试与分层验证记录，见[验证记录](VALIDATION-REPORT.md)。

原版功能（语录、图库、缩放、音效、真实 WASAPI 音乐律动、桌面/跟随、提醒、用量账本、更新与恢复）**保留**，未做删减。
