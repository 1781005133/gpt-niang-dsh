# GPT龙娘 · DSH独立版

版本 **0.1.0-beta.1**，Windows 10/11 x64。基于 T7moris/GPT-Niang v1.4.0-beta.3 的独立非商业个人移植。保留原作者与贡献者署名；不是上游官方发布，不依赖小鲸鱼，不修改原版龙娘或现有GPT订阅插件。

> **独立Beta测试版，未自动安装。** 已在普通临时目录保持sandbox开启通过隐藏渲染及真实角色／菜单界面测试；真实账号、真实音乐设备、跨屏及登录启动仍需另行验收。请完整解压到普通本地目录运行：带Low完整性标签的隔离开发工作区会与Chromium沙箱冲突。不要以管理员运行、修改标签或关闭安全防护来绕过该限制。

## 功能

保留龙娘额度气泡、39句加权语录、语录编辑、独立角色与气泡缩放、形象图库、按压回弹、点击声音、自定义WAV、自动语录、变色、真实WASAPI音乐律动、跟随窗口/桌面拖拽/置顶、回答结束提醒、token四卡与手动单价费用账本、单实例守护和更新失败恢复。新增DSH宿主模式，仍可选Codex模式。

订阅百分比不是金钱余额，也不能由tokens换算。费用只是本机手动单价估算；人民币与美元不混合，未定价部分不会按零元处理。真实窗口/多屏/音频/登录启动的验证状态以交付报告为准。

## 安装前

- 本包自带Electron/Node运行环境，无需额外安装Node。
- DSH模式需要另行安装本项目的 **dsh-gpt-companion-bridge** 配套DSH插件，并启用已有的GPT订阅接入插件。桥接安装必须用当前DSH宿主支持的插件管理入口；桌面端不能把`--profile web`当成desktop安装方式。
- 本桌面安装器**不自动安装/改写DSH插件**，不需要外部Codex客户端，也不修改小鲸鱼。桥接未就绪时显示未连接；可先切换桌面模式使用角色/语录/音乐。
- 完整解压后再运行，不要在压缩包内执行。

## 独立桌面安装与使用

1. 运行本包的`安装独立龙娘.cmd`，只安装本项目到`%USERPROFILE%\.dsh-gpt-companion\app`，个人数据位于同级`state`。
2. 安装器注册本项目独立的当前用户登录任务与启动快捷方式；已有本项目版本升级会保留个人数据。不会查找/接管原版GPT娘安装。
3. 运行`打开独立龙娘.cmd`，打开DSH主窗口；右键角色打开设置。
4. 在「显示与位置」选择DSH GPT订阅或Codex客户端，选择跟随宿主或桌面自由拖动。人物/气泡可分别缩放。可见时才能开启音乐律动。
5. 用量面板默认补读DSH数值档案，范围为桥接启用并在线期间已观测的记录，不是平台完整账单。若使用原Codex账本，先切换来源至Codex；手动目录／恢复自动只影响Codex来源，不与DSH记录混合。

仅希望验证安装包、不注册任何东西，可从命令行运行`安装独立龙娘.cmd --check`。仅显式传入`--codex-plugin`才尝试在Codex中注册**本项目独立名称**的MCP工具；普通DSH安装不需要此选项。

## 可选：在DSH连接原有MCP工具

原有stdio MCP额度查询与角色控制接口也保留，不要求安装Codex客户端。若要让DSH模型调用它，在DSH支持的MCP设置入口**另行确认添加**，命令填写已安装独立程序的绝对路径，参数为`--mcp`。例如（替换用户名）：

```json
{"mcpServers":{"dsh-gpt-companion":{"command":"C:/Users/<用户名>/.dsh-gpt-companion/app/native/DSHDragon.Start.exe","args":["--mcp"]}}}
```

包内 [Codex插件描述](.mcp.json) 使用Codex专属路径变量；不要把该变量原样填入DSH。订阅桥接和MCP控制是独立组件，桌面安装器不会自动修改DSH配置，也不会替换现有小鲸鱼工具。

DSH来源的headless MCP查询返回带`observedAt`及有效期的桥接观测，不抢占桌面控制者，也不会绕过隐藏节流去强刷。真正的新RPC强制刷新由角色气泡／菜单的显式刷新触发；Codex来源仍保留原CLI查询。没有有效观测时返回未连接／过期，不把缓存冒称刚查询成功。

## 桥接安全与限制

桥接客户端通过DSH现有已认证连接调用订阅只读RPC，再将严格白名单投影交给自己的宿主接口；桌面程序仅读取自己的本机快照。没有新HTTP监听端口，不复制Cookie/OAuth，不读取认证文件或聊天正文。

DSH关闭、客户端不可用、登录失效或快照过期时显示未知/断开，不把旧额度当实时，也不会虚构0%或100%。会话用量来自官方数值投影，订阅额度和费用估算互相独立。标题默认用脱敏标签，不复制原聊天标题。快照仍受当前Windows用户文件权限边界保护，不宣称防御已取得同一用户写权限的恶意程序。

可见时默认每60秒查询订阅额度；手动刷新通过既有鉴权通道请求真实新观测并显示排队／限速／超时结果，隐藏时暂停额度查询。数值档案按当前已验证身份分开保存，关闭面板不会主动清除未导入记录；初始化／补读中、容量上限或I/O缺口会明确提示，不把不完整统计冒充完整消费。

## 升级、停用、卸载

- 尚未配置独立公共发行源；「检查并更新」会明确提示仅手动升级，**绝不下载原GPT-Niang更新覆盖本项目**。
- 手动升级：从新版独立包运行安装器，校验程序身份/架构/SHA256全清单并保留个人数据，失败按本项目事务记录恢复。
- `停用独立龙娘.cmd`只停止本项目、移除本项目登录任务及启动快捷方式，保留程序和个人数据。
- 彻底移除：先停用，确认进程退出后再删除本项目程序目录；需要清除个人数据时另行删除其`state`。DSH桥接包通过DSH支持的管理入口单独移除。**不要删除小鲸鱼、原版GPT娘、订阅插件或其数据目录。**
